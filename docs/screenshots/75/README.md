# #75 C 응시 결과 표·응시자 상세 스크린샷

찍은 커밋 `c7978a3`의 로컬 스택: 서버 이미지(`docker/server.Dockerfile`, wasm 대시보드 포함) + Postgres 17. 시드는 SQL 직접(조직·채용 시험 문항 2개·응시자 3명 — 채점 완료+평가 완료 / 응시 중 / 초대만, 서명된 과정 로그 사건 포함), 로그인은 세션 쿠키 `pl_session`을 `sessions`에 직접 넣었다. 운영 auth·실제 API 키 없음.

파일 이름 `<화면>-<desktop 1440|mobile 390>-<light|dark>.jpg`(Playwright `colorScheme`, 전체 페이지, JPEG 55). 390폭은 1180 미만이라 왼쪽 메뉴가 위 아이콘 줄이 된다.

| 화면 | 주소(해시) | 무엇 |
|---|---|---|
| `exam-results` | `#/orgs/<org>/exams/<exam>/results` | 시험 상세 「응시 결과」 — 요약 칸·상태 칩·응시자 표 |
| `candidate-conversations` | `…/candidates/<invite>/conversations` | 응시자 상세 「대화와 점수」 — 대화 탭·원문·점수 계산식·대화 평가 항목 |
| `candidate-evidence-click` | 같은 주소 | 근거 칩 「대화 B · 턴 3」을 눌러 대화 B로 바뀐 상태 |

### 390폭 가로 넘침(측정, `overflow.json`)

`document.documentElement.scrollWidth - clientWidth`는 모든 화면 0px(라이트·다크 같다). 안쪽 스크롤 컨테이너는 아래와 같다(뷰포트 오른쪽을 넘는 요소는 이 컨테이너 안쪽 내용이라 화면 밖으로 새지 않는다).

| 화면 | 문서 넘침 | 안쪽 스크롤 컨테이너 |
|---|---|---|
| `exam-results` | 0px | `aside.sc-sidenav` 450>390, `nav.sc-tabs` 446>358, `div.sc-table-scroll` 733>356 |
| `candidate-conversations` · `evidence-click` · `replay` · `signals` · `report` · `erase-confirm` | 0px | `aside.sc-sidenav` 450>390, `nav.sc-tabs` 477~478>358 |

## 알아낸 결함 목록(고치지 않음)

1. 390폭 `exam-results`: 응시자 표가 안쪽으로 가로 스크롤(733>356) — 첫 화면에 「최종 점…」·「73」이 잘려 점수 열이 거의 안 보이고 스크롤할 수 있다는 표시가 없다. 모바일에서는 점수를 먼저 보이게 하거나 카드형으로 바꿀 만하다.
2. 390폭 위쪽 아이콘 메뉴(`aside.sc-sidenav` 450>390): 항목이 7개라 오른쪽 끝(내 연습 기록 다음의 운영자 화면)이 화면 밖이고 스크롤 표시가 없다.
3. 390폭 응시자 상세 탭(`nav.sc-tabs` 477>358): 「웹캠 사진」·「AI 리포트」가 잘려 보이고(「웹캠 A」) 스크롤 표시가 없다. 응시 결과 탭도 「실시간 감독」이 잘린다.
4. 390폭 이동 경로: 가운데 항목이 「› › 」로 비어 보일 만큼 잘리고 시험 이름도 「2026 하반기…」로 잘린다 — 어느 단계인지 읽기 어렵다.
5. 390폭 데이터 삭제 확인 상자: 양쪽 여백 없이 화면 가장자리에 붙어 있고, 상자 위쪽 선이 상단에 맞닿는다. (전체 페이지 캡처에서는 반투명 막이 첫 뷰포트(844px)까지만 덮인 것으로 보이는데, 이것은 캡처 방식 탓일 수 있다.)
6. 데스크톱 전체 페이지에서 왼쪽 메뉴 배경이 뷰포트 높이(900px)에서 끊긴다(긴 화면에서 메뉴 영역만 짧게 보임). 캡처 방식(스크롤하지 않는 sticky) 탓일 수 있어 실제 브라우저 확인이 필요하다.
7. 과정 다시보기: 사건 줄에 종류 이름만 있고 대화 id·메시지·모델 답·시험 통과 여부 같은 내용이 보이지 않아 「과정」을 다시 볼 수 없다(대화 턴 7개가 똑같은 「대화 턴」). 모든 줄에 붙은 「늦게 받음」 칩은 시드가 받은 시각을 지금으로 넣은 탓이라 결함 아님(실제 업로드에서는 사라지는지 확인 필요).
8. `exam-results` 요약 칸 라벨의 낱말 사이가 넓어 보인다(「평균  최종  점수」) — 헤드리스 글꼴 탓일 수 있어 실제 브라우저에서 확인 필요.
9. 응시 중·초대만 줄에서 점수 열이 모두 「—」라 이유(채점 대기인지 응시 전인지)가 열에서는 안 보이고 상태 칩에만 있다. 「삭제까지」 열은 초대만 줄이 375일로 다른 줄(365일)과 달라 이유 설명이 없다.
10. 다크: 「데이터 삭제」 버튼이 연한 살구색 바탕이라 라이트의 짙은 빨강과 인상이 다르다 — 글자 대비는 눈으로만 봤고 수치로 재지 않았다.

시드 쪽 한계: 웹캠 사진 탭은 사진이 없어 찍지 않았다. 의심 신호 「포커스 이탈·복귀」는 한 줄로 합쳐 보인다(정상).

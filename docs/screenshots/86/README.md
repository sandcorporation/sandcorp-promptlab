# #86 이용약관 동의 화면 스크린샷

작업 트리(브랜치 t86, 커밋 전 변경 포함)로 서버 이미지(`docker/server.Dockerfile`, wasm 대시보드 포함)를 빌드하고 Postgres 17 컨테이너와 같은 도커 네트워크에 띄웠다. 시드는 SQL 직접(사용자 3명 `m_`+ULID 꼴, 조직 1개, 약관 판 `2026-11-07` 동의 기록, 초대 토큰 해시), 로그인은 `sessions`에 세션 쿠키 `pl_session`의 sha256을 직접 넣었다. 운영 auth·실제 API 키 없음. Playwright(헤드리스 크롬)로 1440x900 전체 페이지, `colorScheme` 라이트·다크, JPEG 품질 55.

| 화면 | 주소 | 보이는 것 |
|---|---|---|
| `create-org` | `#/`(조직 없는 사용자) | 조직 이름 입력 후 약관 체크 켬 — 「조직 만들기」 단추 활성(강조색) |
| `create-org-unchecked` | 같은 주소 | 이름은 채우고 체크 안 함 — 단추 비활성(회색) |
| `invite-accept` | `/invite/<토큰>` → `#/invite/<토큰>` | 「초대 수락」 패널, 체크 켬 — 「동의하고 들어가기」 활성, 「나중에」 |
| `members-terms` | `#/orgs/<org>/members` | 구성원 표 아래 「이용약관 2026-11-07 동의 · 11-07 10:30:00 · 약관 보기」 줄 |

파일명은 `<화면>-desktop-<light|dark>.jpg`(8장). 모든 화면에서 「이용약관」·「약관 보기」는 링크 색 밑줄로 보이고, 체크·단추 상태는 의도대로이며 라이트·다크 모두 읽힌다.

## 눈에 띈 결함(고치지 않음)

1. `create-org`: 동의 체크가 「조직 만들기」 단추 아래에 있다 — 단추를 먼저 보고 누르기 쉽고, 체크하면 단추가 켜진다는 연결이 시각적으로 약하다(입력 → 체크 → 단추 순이 자연스럽다).
2. `create-org-unchecked`: 단추가 비활성인 이유(약관 미동의)를 알려 주는 문구가 없다. 입력창에 포커스 링이 남아 있는 것은 캡처 때 채운 탓.
3. `members-terms`: 동의 시각이 연도 없이 「11-07 10:30:00」으로 나온다(`kst` 도우미 형식). 동의 기록은 해를 넘겨 남으니 연도가 있는 편이 낫다. 또 표 아래 줄 위쪽 여백이 커서(표와 줄 사이 약 70px) 표와 떨어져 보인다.
4. `invite-accept`: 「나중에」 단추가 라이트에서 거의 검정 바탕이라 주 단추보다 눈에 띄고, 다크에서는 흰 바탕이다 — 보조 단추 치고 무겁다.
5. `invite-accept`·`create-org`: 사이드바 제목이 「내 조직 / 조직 고르기·만들기」로 초대 페이지에서도 그대로다(초대 수락 중임을 메뉴에서는 알 수 없음, 사소함).
